# Data protokol eksperimen

`lms_split_indices.csv` menyimpan keanggotaan holdout LMS yang tetap.
`pendikom_ils_labels.csv` berisi label kuesioner ILS independen untuk 461
peserta beserta keanggotaan holdout. Label ini hanya dipakai untuk evaluasi;
tidak dimasukkan sebagai prediktor atau pembentuk cluster.
`pendikom_feature_plan.csv` mendokumentasikan indikator yang dipakai.
Keanggotaan dan urutan peserta dipertahankan agar protokol 70:30 konsisten.
